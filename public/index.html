Pagamentos

Negociação pelo WhatsApp, confirmação pelo site.

O pagamento é combinado com a administração pelo WhatsApp.

Depois de solicitar a reserva, use o botão de WhatsApp no acompanhamento. Pix ou transferência são informados durante o atendimento e os dados bancários não ficam publicados no site.

O botão “Já realizei um pagamento” apenas avisa a administração. A reserva só muda para confirmada depois da conferência do crédito no banco, registro no painel, validação das demais exigências e nova checagem de conflito de datas.

Privacidade

Dados mínimos, finalidade clara.

Os dados de contato e reserva são usados para atender a solicitação, organizar a hospedagem e manter os registros operacionais necessários. Avaliações só são publicadas após moderação. Solicitações de correção ou exclusão devem ser tratadas pela administração, observadas as obrigações legais de retenção.

Este sistema não armazena senha do hóspede nem dados de cartão. Pix e transferência são registrados somente após conferência bancária pela administração.
