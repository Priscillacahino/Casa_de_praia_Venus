    Pagamentos
Negociação pelo WhatsApp, confirmação pelo site.

    
O pagamento é combinado com a administração pelo WhatsApp.

    
Depois de solicitar a reserva, use o botão de WhatsApp no acompanhamento. Os dados para Pix ou transferência são informados durante o atendimento, e os dados bancários não ficam publicados no site.

    
Pagamentos, links de cartão e reembolsos são tratados exclusivamente pelo WhatsApp. O site não recebe nem registra transações financeiras; a administração confirma a reserva manualmente após as verificações externas e a validação do termo e das datas.

  


  

    Privacidade
Dados mínimos, finalidade clara.

    
Os dados de contato e reserva são usados para atender a solicitação, organizar a hospedagem e manter os registros operacionais necessários. Avaliações só são publicadas após moderação. Solicitações de correção ou exclusão devem ser tratadas pela administração, observadas as obrigações legais de retenção.

    
Este sistema não solicita senhas do hóspede, dados de cartão, contas bancárias ou comprovantes, nem aceita novos registros de transações financeiras. O atendimento financeiro é externo, pelo WhatsApp.
